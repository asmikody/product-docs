# Sony BRAVIA 3

## 1. Sony BRAVIA 3 Overview

- Sony BRAVIA 3 is a Direct LED 4K Google TV.
- Sony BRAVIA 3 uses the model number K-55S30B.
- Sony BRAVIA 3 was released for the 2024 model year.
- Sony BRAVIA 3 is documented in Sony India support material.

## 2. Sony BRAVIA 3 Display and Picture Quality

- Sony BRAVIA 3 is available with a 55 inches (54.6 inches measured diagonally) display.
- Sony BRAVIA 3 uses Direct LED LCD display technology.
- Sony BRAVIA 3 supports a 3840 × 2160 pixels resolution.
- Sony BRAVIA 3 supports a 50 Hz panel refresh rate.
- Sony BRAVIA 3 supports HDR10, HLG and Dolby Vision for HDR content.
- Sony BRAVIA 3 uses the 4K HDR Processor X1.
- Sony BRAVIA 3 features TRILUMINOS Pro, Dynamic Contrast Enhancer, 4K X-Reality PRO and Motionflow XR 200.

## 3. Sony BRAVIA 3 Smart TV Features

- Sony BRAVIA 3 runs on Google TV.
- Sony BRAVIA 3 supports Google TV, Google Play Store, Google Cast, Apple AirPlay and Apple HomeKit.
- Sony BRAVIA 3 supports Google Assistant voice search with a built-in microphone.
- Sony BRAVIA 3 supports mobile casting and screen mirroring through supported Google Cast or Apple AirPlay features.

## 4. Sony BRAVIA 3 Audio and Sound

- Sony BRAVIA 3 uses Full Range Bass Reflex speakers ×2.
- Sony BRAVIA 3 provides 20 W of rated audio output.
- Sony BRAVIA 3 supports Dolby Atmos.
- Sony BRAVIA 3 has the following DTS specification: DTS not supported.
- Sony BRAVIA 3 features X-Balanced Speaker and Sony sound processing.

## 5. Sony BRAVIA 3 Connectivity and Ports

- Sony BRAVIA 3 includes 4 HDMI inputs.
- Sony BRAVIA 3 supports eARC and ALLM.
- Sony BRAVIA 3 includes 2 USB ports.
- Sony BRAVIA 3 includes 1 digital audio output.
- Sony BRAVIA 3 includes 1 LAN input.
- Sony BRAVIA 3 supports Wi-Fi 5-class 802.11a/b/g/n/ac and Bluetooth 5.3.

## 6. Sony BRAVIA 3 Gaming Features

- Sony BRAVIA 3 supports No VRR, ALLM and 4K 60 Hz-class input.
- Sony BRAVIA 3 supports compatible PCs and game consoles through HDMI.
- Sony BRAVIA 3 supports Game picture mode for compatible gaming sources.
- Sony BRAVIA 3 supports PlayStation 5 picture features where specified by Sony.

## 7. Sony BRAVIA 3 Design and Physical Specifications

- Sony BRAVIA 3 has the following physical specification: 1,233 × 713 × 72 mm without stand; 15.4 kg without stand; VESA 300 × 300 mm; Sony specifies the remaining stand details.
- Sony BRAVIA 3 supports wall mounting through its specified VESA pattern where one is published.
- Sony BRAVIA 3 uses a Sony-specified table-top stand configuration.

## 8. Sony BRAVIA 3 Compatibility and Useful Features

- Sony BRAVIA 3 is compatible with HDMI-connected media players, PCs and game consoles.
- Sony BRAVIA 3 supports BRAVIA Sync and HDMI-CEC where specified.
- Sony BRAVIA 3 supports Sony accessibility features provided by its software.

## 9. Sony BRAVIA 3 Package and Warranty

- Sony BRAVIA 3 includes Table Top Stand, Voice Remote Control, batteries, AC power cord and setup documentation.
- Sony BRAVIA 3 is covered by the applicable Sony India warranty terms for the specific purchase and region.
