# Sony BRAVIA 3 II

## 1. Sony BRAVIA 3 II Overview

- Sony BRAVIA 3 II is a Direct LED 4K Google TV.
- Sony BRAVIA 3 II uses the model number K-55XR30M2.
- Sony BRAVIA 3 II was released for the 2026 model year.
- Sony BRAVIA 3 II is documented in Sony India support material.

- Sony BRAVIA 3 II is available with a 55 inches (54.6 inches measured diagonally) display.
- Sony BRAVIA 3 II uses Direct LED LCD display technology.
- Sony BRAVIA 3 II supports a 3840 × 2160 pixels resolution.
- Sony BRAVIA 3 II supports a 120 Hz panel refresh rate.
- Sony BRAVIA 3 II supports HDR10, HLG and Dolby Vision for HDR content.
- Sony BRAVIA 3 II uses the XR Processor.
- Sony BRAVIA 3 II features XR TRILUMINOS Pro, Dynamic Contrast Enhancer, XR Clear Image and Sony HDR picture processing.
