# Samsung S90F


## 1. Samsung S90F Overview
• Samsung S90F is an OLED 4K smart television from Samsung's 2025 lineup.
• Samsung S90F uses model number QA65S90FAELXL for the 65-inch India-market variant documented here.
• Samsung S90F is available in multiple screen sizes, including 65-inch and 83-inch class sizes in the India listings.
• Samsung S90F runs on Samsung Tizen Smart TV software with Samsung Vision AI features.

## 2. Samsung S90F Display and Picture Quality
• Samsung S90F uses an OLED display with self-illuminating pixels.
• Samsung S90F provides 4K resolution at 3840 × 2160 pixels.
• Samsung S90F supports OLED HDR+ and HDR10+ Adaptive and Gaming.
• Samsung S90F supports Motion Xcelerator 144Hz for compatible high-frame-rate content.
• Samsung S90F supports 4K AI Upscaling Pro for compatible lower-resolution content.
• Samsung S90F supports Ultra Viewing Angle for compatible viewing positions.
• Samsung S90F supports Filmmaker Mode and HDR brightness optimization.

• Samsung S90F includes Samsung Knox security features for supported network-based services.
