# Toshiba 43C350NP

## 1. Toshiba 43C350NP Overview
• Toshiba 43C350NP is a 43-inch 4K Ultra HD LED Google TV from Toshiba's C350NP series.
• Toshiba 43C350NP uses model identifier 43C350NP.
• Toshiba 43C350NP runs on Google TV.
• Toshiba 43C350NP uses the REGZA Engine ZR for picture processing.

• Toshiba 43C350NP supports a 60Hz refresh rate.
• Toshiba 43C350NP supports HDR10, HLG and Dolby Vision.
• Toshiba 43C350NP supports MEMC and AI 4K upscaling.
• Toshiba 43C350NP supports Filmmaker Mode and a 178-degree viewing angle.
