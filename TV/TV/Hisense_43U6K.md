# Hisense 43U6K

## 1. Hisense 43U6K Overview
• Hisense 43U6K is a 43-inch QLED 4K smart television from Hisense's U6K series.
• Hisense 43U6K uses Direct Full Array QLED display technology.
• Hisense 43U6K runs on Google TV.
• Hisense 43U6K provides 3840 × 2160 4K resolution.

## 2. Hisense 43U6K Display and Picture Quality
• Hisense 43U6K uses a QLED panel with direct full-array backlighting.
• Hisense 43U6K provides 3840 × 2160 pixel resolution.
• Hisense 43U6K supports a high-refresh-rate mode up to 120Hz.
• Hisense 43U6K supports HDR10, Dolby Vision and HLG.
• Hisense 43U6K supports MEMC and smooth-motion processing.
• Hisense 43U6K supports Cinema, Game and Filmmaker Mode picture settings.
