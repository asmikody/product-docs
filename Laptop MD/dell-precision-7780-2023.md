# Dell Precision 7780 (2023) Buyer's Guide

## 1. Dell Precision 7780 (2023) Overview and Design
- The Dell Precision 7780 (2023) officially launched in March 2023 with heavy-duty workstation availability throughout 2024.
- The Dell Precision 7780 (2023) belongs to the 17.3-inch desktop replacement enterprise mobile workstation laptop class.
- The Dell Precision 7780 (2023) chassis is constructed from Titan Grey aluminum with internal magnesium alloy subframe reinforcement.
- The Dell Precision 7780 (2023) carries a heavy-duty workstation starting weight of approximately 3.02 kg.
- The Dell Precision 7780 (2023) measures an expansive workstation chassis profile thickness of 28.5 mm.
- The Dell Precision 7780 (2023) targets petroleum engineers, structural CAD architects, machine learning researchers, and broadcast video studios.

## 2. Dell Precision 7780 (2023) Configurations
- The Dell Precision 7780 (2023) base config equips Core i7-13850HX, RTX A1000 6 GB, 32 GB CAMM, 512 GB SSD, FHD.
- The Dell Precision 7780 (2023) mid-tier config adds an NVIDIA RTX 3500 Ada 12 GB GPU and a 1 TB SSD.
- The Dell Precision 7780 (2023) performance config adds an NVIDIA RTX 4000 Ada 12 GB discrete GPU and 64 GB CAMM.
- The Dell Precision 7780 (2023) flagship config adds an NVIDIA RTX 5000 Ada 16 GB GPU, Core i9-13950HX, and 128 GB CAMM.

## 3. Dell Precision 7780 (2023) CPU Specifications
- The Dell Precision 7780 (2023) CPU is built on the Intel Raptor Lake-HX desktop-derived mobile microarchitecture.
- The Dell Precision 7780 (2023) CPU compute silicon is fabricated on the Intel 7 10 nm process node.
- The Dell Precision 7780 (2023) CPU utilizes the Intel 13th Gen Core HX vPro enterprise mobile series.
- The Dell Precision 7780 (2023) flagship processor configuration is the Intel Core i9-13950HX with vPro Enterprise.
- The Dell Precision 7780 (2023) primary processor configuration is the Intel Core i7-13850HX with vPro Enterprise.
- The Dell Precision 7780 (2023) Core i9-13950HX features 24 physical cores and 32 concurrent threads.
- The Dell Precision 7780 (2023) CPU core layout comprises 8 Raptor Cove P-cores and 16 Gracemont E-cores.
- The Dell Precision 7780 (2023) Core i9-13950HX P-cores operate at a 2.2 GHz base and up to 5.5 GHz boost.
- The Dell Precision 7780 (2023) Core i9-13950HX E-cores operate at a 1.6 GHz base and up to 4.0 GHz boost.
- The Dell Precision 7780 (2023) processor incorporates a massive 36 MB of shared Intel Smart Cache L3.
- The Dell Precision 7780 (2023) memory controller supports Dell CAMM or optional SO-DIMM DDR5-5600 MT/s memory up to 128 GB.
- The Dell Precision 7780 (2023) CPU integrates Intel UHD Graphics with 32 execution units operating at 1.65 GHz.
- The Dell Precision 7780 (2023) CPU instruction support includes x86-64, SSE4.2, AVX2, and Intel DL Boost.
- The Dell Precision 7780 (2023) CPU does not support AVX-512 instructions due to architectural Intel hybrid core parity.
- The Dell Precision 7780 (2023) CPU provides dedicated PCIe 4.0 lanes for up to four internal NVMe storage drives.
- The Dell Precision 7780 (2023) CPU integrates dual native Thunderbolt 4 host controllers providing 40 Gbps bidirectional bandwidth.

- The Dell Precision 7780 (2023) discrete GPU is built on the NVIDIA Ada Lovelace professional workstation microarchitecture.
- The Dell Precision 7780 (2023) GPU silicon is fabricated on a custom TSMC 4N NVIDIA process node.
- The Dell Precision 7780 (2023) flagship features an NVIDIA RTX 5000 Ada Generation Laptop GPU with 9,728 CUDA cores.
- The Dell Precision 7780 (2023) tier-two features an NVIDIA RTX 4000 Ada Generation Laptop GPU with 7,424 CUDA cores.
- The Dell Precision 7780 (2023) tier-three features an NVIDIA RTX 3500 Ada Generation Laptop GPU with 5,120 CUDA cores.
- The Dell Precision 7780 (2023) base features an NVIDIA RTX A1000 Laptop GPU with 2,560 CUDA cores.
- The Dell Precision 7780 (2023) RTX 5000 Ada GPU equips 16 GB of ECC GDDR6 VRAM across a 256-bit memory bus.
- The Dell Precision 7780 (2023) RTX 5000 Ada delivers a maximum memory bandwidth of 576 GB/s at 18 Gbps effective speed.
- The Dell Precision 7780 (2023) discrete GPU operates at a maximum configured 130 W base TGP plus 20 W Dynamic Boost.
- The Dell Precision 7780 (2023) discrete GPU achieves a maximum total graphics power rating of 150 W TGP.
- The Dell Precision 7780 (2023) delivers full Independent Software Vendor (ISV) certifications for CATIA, Maya, Revit, and SolidWorks.
- The Dell Precision 7780 (2023) GPU supports DirectX 12 Ultimate, Vulkan 1.3, OpenGL 4.6, and OpenCL 3.0 APIs.
- The Dell Precision 7780 (2023) GPU supports NVIDIA CUDA 12 and enterprise OptiX ray tracing compute architectures.
